# Toneii - DnD Edition (Multi-Layer Soundboard v3.7)

ยินดีต้อนรับสู่ Toneii โปรเจกต์ Soundboard สำหรับเกม Tabletop RPG (D&D) ที่ซิงค์เสียงแบบ Real-time ให้ผู้เล่นทุกคนได้ยินพร้อมกันทุกวินาที!

## ✨ ฟีเจอร์ใหม่ในเวอร์ชัน 3.7 (Multi-Layer BGM & Loop Control)
1. **ปุ่ม Loop แยกอิสระในแต่ละ BGM (`🔁 Loop: OFF / ON`):**
   - ค่าเริ่มต้นของทุก BGM จะเป็น `Loop: OFF` (เมื่อเพลงเล่นจบจะหยุดเองอัตโนมัติและรีเซ็ตกลับไป 0:00)
   - หากต้องการให้เพลงหรือเสียงบรรยากาศเล่นวนซ้ำไม่รู้จบ สามารถกดปุ่มสลับเป็น `🔁 Loop: ON` ได้ทันที (กดเปิด/ปิดระหว่างที่เพลงกำลังเล่นอยู่ได้เลย)
2. **ระบบ Multi-Layer BGM (เปิด BGM ซ้อนกันได้หลายแทร็ก):**
   - แต่ละแทร็กในหมวด BGM มีเครื่องเล่นแยกอิสระจากกัน 100%
   - DM สามารถเปิดเสียงบรรยากาศ (เช่น เสียงสายลม เสียงฝน เสียงสนามรบ) คลอไว้ แล้วกดเปิดเพลงดนตรีอีกแทร็กซ้อนทับขึ้นมาได้โดยที่เสียงเก่าไม่ดับ
   - ปรับระดับเสียง (Volume), เลื่อนเวลา (Seek Bar), กด Pause/Resume หรือ Stop แยกแต่ละแทร็กได้อย่างอิสระ
   - มีไฟสถานะสีเขียวกระพริบหน้าชื่อแทร็กที่กำลังเล่นสด เพื่อให้ DM มองเห็นได้ง่ายว่ากำลังเปิดเสียงอะไรซ้อนกันอยู่บ้าง
   - รองรับการซิงค์ให้ผู้เล่นที่เข้ามาทีหลัง (Late-Joiner Sync) ได้ยินทุกแทร็กที่กำลังเปิดซ้อนกันอยู่ตรงตามวินาทีจริงทันที
