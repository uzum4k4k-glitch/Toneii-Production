# Toneii - DnD Edition (Real-time Soundboard v3.6)

ยินดีต้อนรับสู่ Toneii โปรเจกต์ Soundboard สำหรับเกม Tabletop RPG (D&D) ที่ซิงค์เสียงแบบ Real-time ให้ผู้เล่นทุกคนได้ยินพร้อมกันทุกวินาที!

## ✨ ฟีเจอร์หลักในเวอร์ชัน 3.6 (Real-time Sync Update)
- **ปุ่มควบคุม BGM สไตล์ YouTube:** ยุบรวมปุ่ม Play และ Pause เข้าเป็นปุ่มสลับสถานะปุ่มเดียว (▶ Play / ❚❚ Pause / ▶ Resume) พร้อมตัวเลขบอกเวลาเพลงแบบเรียลไทม์
- **Late-Joiner Real-time Sync:** ผู้เล่นที่กดเข้าห้องตามมาทีหลังจะได้ยินเพลง BGM ที่กำลังเปิดอยู่ในวินาทีเดียวกับที่ DM กำลังฟังอยู่ทันที โดยที่ DM ไม่ต้องกดเริ่มเพลงใหม่
- **Auto-Sync ไฟล์เสียงถาวรจาก GitHub:** เพียงอัปโหลดไฟล์เสียงใส่โฟลเดอร์ src/static/audio บน GitHub (ตั้งชื่อขึ้นต้นด้วย bgm_ สำหรับเพลงพื้นหลัง) ระบบจะนำเข้าฐานข้อมูลให้อัตโนมัติทุกครั้งที่เปิดเซิร์ฟเวอร์
